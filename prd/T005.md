# T005 — Verification and pilot readiness

## Metadata

- Last specification update: 2026-09-12

## Objective

Verify the Blackboard skill/CLI against its mechanical contracts, document known MVP limitations, and package a pilot-ready repository with complete PRD/Progress/Git history.

## Scope

### In scope

- unit/integration tests for claims, concurrency, note loops, consensus, objections, materialization, consistency, and provenance;
- CLI smoke checks;
- final canonical-state consistency check;
- pilot protocol document;
- ZIP including `.git`.

### Out of scope

- executing the multi-agent pilot itself;
- Telegram adapters;
- framework-specific installation automation.

## Contracts and interfaces

The implementation is pilot-ready only when automated tests pass, `bb check` passes on the implementation repository, all implementation macro-tasks are COMPLETE, and the Git working tree is clean before packaging.

## Sub-tasks

### T005-SUB001 — Automated behavioral tests

- Goal: exercise critical Blackboard mechanics including concurrent claim contention.
- Dependencies: —
- Acceptance criteria:
  - Claim exclusivity, expiry takeover, and ownership checks are tested.
  - Notes/promotion and proposal consensus/objection paths are tested.
  - NEW_TASK materialization and provenance are tested.
  - Consistency checker is tested.
- Verification:
  - `python -m unittest discover -s tests -v`

### T005-SUB002 — Pilot protocol and known-risk documentation

- Goal: prepare the first 4-agent pilot without pre-solving the expected emergent problems.
- Dependencies: T005-SUB001
- Acceptance criteria:
  - Pilot starts from an empty task index/brief-only state.
  - Observability and deliberate perturbations are documented.
  - Known MVP limitations are explicit.
- Verification:
  - Review `PILOT.md`.

### T005-SUB003 — Final packaging

- Goal: finish canonical project state and create ZIP with `.git`.
- Dependencies: T005-SUB001, T005-SUB002
- Acceptance criteria:
  - `bb check` passes.
  - Git working tree is clean.
  - ZIP contains `.git`, `SKILL.md`, `PRD.md`, CLI code, tests, and pilot documentation.
- Verification:
  - Inspect ZIP manifest and run `git log` in extracted copy if needed.

## Risks

- Automated tests cannot reproduce all shared-working-tree races that the real heterogeneous-agent pilot may expose.

## Open questions

- Real source-code overlap policy intentionally remains a pilot question.
